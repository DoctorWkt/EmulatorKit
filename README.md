# Rosco r2 Emulator

This is an emulator for the Rosco r2 m68k SBC. I've essentially forked
https://github.com/EtchedPixels/EmulatorKit, removed the emulators that
I don't need and modified an existing emulator to match the Rosco r2
hardware.

The aim is to get the Rosco ROM, my port of `xv6` and Fuzix to boot on
the emulator. Later, if/when it all works I'll tidy it up and submit it
back to the EmulatorKit.
